# Ideias (Fase 0)

> **O que é:** a lista das ideias de sistema e a ficha de cada uma, preenchida na **Fase 0 — Descoberta** de [modulos/cicloDesenvolvimento.md](../modulos/cicloDesenvolvimento.template.md).
> **Regra:** ideia **não** entra no catálogo de sistemas nem vira ficha em `sistemas/` antes do portão **aprovar**. Ideia parada não vira lixo: fica aqui, com a data, e a revisão periódica da doc cobra.
> Voltar ao hub: [DocumentacaoPadrao.md](../DocumentacaoPadrao.template.md)

## Lista

| Ideia | Portão | Desde | Quem decide |
|-------|--------|-------|-------------|

> Portão: **ideia** (ainda na entrevista) · **amadurecer** · **aprovada** (com o "pode fazer") · **arquivada** (sempre com motivo).

## Modelo da ficha

Copiar este bloco para cada ideia nova, abaixo da lista. A IA pergunta **uma por vez, na ordem**; a pergunta 11 é feita a cada projeto (não vem preenchida).

```
## <Título>

1. Título do sistema: …
2. Detalhamento: o que é o sistema: …
3. Objetivo: que dor resolve (nas suas palavras): …
4. Para quem: …
5. Como é feito hoje: …
6. Como saber que deu certo: …
7. O que fica de fora: …
8. Apetite: quanto tempo vale investir: …
9. Já existe pronto no mercado ou em código aberto?: …
10. Riscos: LGPD, rede/internet, custo de IA, dependências: …
11. Quem decide: …
12. Dúvidas abertas: …
13. Propostas da IA (não aprovadas): …

Portão: <ideia | amadurecer | aprovada | arquivada> — motivo: …
```
