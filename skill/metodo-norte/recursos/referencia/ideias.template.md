# Ideias (Fase 1)

> **O que é:** a lista das ideias de sistema e a ficha de cada uma, preenchida na **Fase 1 — Planejamento** de [modulos/cicloDesenvolvimento.md](../modulos/cicloDesenvolvimento.template.md).
> **Regra:** ideia **não** entra no catálogo de sistemas nem vira ficha em `sistemas/` antes da Aprovação da Fase 1. Ideia parada não vira lixo: fica aqui, com a data, e a revisão periódica da doc cobra.
> Voltar ao hub: [DocumentacaoPadrao.md](../DocumentacaoPadrao.template.md)

## Modelo da ficha

Copiar este bloco para cada ideia nova, abaixo da lista. A IA pergunta **uma por vez, na ordem**, em cartão com as opções da Fase 1 (★ = padrão + "Outro"); a pergunta 13 é feita a cada projeto (não vem preenchida).

```
## <Título>

1. Nome do sistema: …
2. O que é o sistema: …
3. Pra que ele serve (que dor resolve, nas suas palavras): …
4. Para quem: …
5. Como é feito hoje: …
6. Como saber que deu certo: …
7. O que fica de fora (Entra na v1 / Fica de fora): …
8. Como será desenvolvido (★ stack padrão · Outro): …
9. Liga a outro sistema ou serviço?: …
10. Apetite: quanto tempo vale investir: …
11. Já existe pronto no mercado ou em código aberto?: …
12. Riscos (só listar): LGPD, internet, custo de IA, sistema externo, certificado digital: …
13. Quem decide: …
14. Dúvidas abertas: …
15. Propostas da IA (não aprovadas): …

Situação: <ideia | amadurecer | aprovada | arquivada> — motivo: …
```
